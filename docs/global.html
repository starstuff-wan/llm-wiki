全局：三个文件各管什么

文件行数职责
src/huffman.h139声明：Huffman 树结点、编码表、比特流、三个算法的接口、PSNR/SSIM
src/huffman.cpp565实现：Huffman 建树与编解码、RLE、LZW、PSNR/SSIM、熵
src/image.h/.cpp34 / 219自己解析 BMP：24 位真彩色 + 8 位灰度，读和写
src/main.cpp688压缩文件格式、压缩/解压调度、性能统计、交互菜单、命令行

调用关系只有一条主线，看清楚这条线，整个程序就懂了：

text
main.cpp
   ├─ loadBmp()            读图 → Image{w,h,channels,data[]}
   ├─ buildFrequency()     统计 256 个灰度值各出现多少次
   ├─ compressData()
   │     ├─ HuffTable::build()     建 Huffman 树 → 码长表
   │     ├─ huffmanEncode()        按码表逐像素写比特
   │     ├─ rleEncode() / lzwEncode()
   ├─ writeIcp()           套上 32 字节文件头，写 .icp
   ├─ readIcp()            读回文件头 + 载荷
   ├─ decompressData()     反向还原
   └─ runAndReport()       算压缩比、耗时、PSNR、SSIM，打印表格
