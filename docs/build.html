编译与运行

用 CMake（推荐）

bash
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build . --config Release

直接用 g++ / MinGW

bash
g++ -std=c++17 -O2 -o icomp src/main.cpp src/huffman.cpp src/image.cpp

用 Visual Studio

新建“空项目”，把 src 下 4 个文件（2 个 .h + 3 个 .cpp）加入项目，语言标准选 C++17。

运行

text
icomp                                          进入交互菜单
icomp info  test.bmp                           查看图像信息
icomp c     test.bmp out.icp huffman           压缩（算法可换 rle / lzw）
icomp d     out.icp back.bmp                   解压
icomp bench test.bmp                           三种算法对比
